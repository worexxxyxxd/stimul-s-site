# СТИМУЛ-С — сайт

Сайт компании СТИМУЛ-С: дагестанский природный камень, облицовка фасадов, цоколь, декор, внутренняя отделка.

Страницы: `index.html`, `uslugi.html`, `kamen.html`, `o-kompanii.html`, `kontakty.html`.

## Фото
Положите фотографии в папку `img/` (см. `img/ФОТО-СЮДА.txt`):
- `hero-house.jpg` — дом с фасадом из камня
- `quarry.jpg` — карьер, горы, заготовки
- `object.jpg` — готовый объект (эффект «старого фото» накладывается автоматически)
